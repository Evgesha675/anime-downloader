# Политика конфиденциальности

Дата вступления в силу: 9 октября 2026 года.

AnimeLib Downloader не собирает, не продаёт и не передаёт разработчику персональные данные пользователей.

Расширение:

- работает только на страницах `animelib.org` и с используемыми сайтом серверами `cdnlibs.org`;
- использует активную авторизованную сессию AnimeLib внутри страницы для получения доступной пользователю информации;
- не сохраняет и не передаёт токен авторизации разработчику или сторонним аналитическим сервисам;
- сохраняет локально только техническое состояние текущей очереди загрузки;
- использует разрешение на загрузки исключительно для сохранения выбранных пользователем видеофайлов;
- не содержит рекламы, аналитики и удалённо исполняемого кода.

Данные обрабатываются локально в браузере пользователя. Сетевые запросы выполняются непосредственно к AnimeLib и его CDN в соответствии с действиями пользователя.

По вопросам конфиденциальности можно создать issue в публичном репозитории проекта.
